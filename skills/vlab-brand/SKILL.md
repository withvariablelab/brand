# Variable Lab brand

Variable Lab is Variable Land's open source arm. This guideline is for Variable Lab and its Projects only, and holds their rules for anything public: sites, READMEs, package pages, images and icons. Variable Land's own products use their own brand. The guideline states rules, never one Project's specifics: a Project's Sign lives in that Project's repository, and a site's page specs live in that site.

Terms in capitals are defined in [glossary.md](glossary.md).

Read the chapter the task touches:

| Task | Chapter |
| --- | --- |
| Any public work: the rules everything else follows | [principles.md](principles.md) |
| Place, size or link the Logo | [logo.md](logo.md) |
| Pick or check a color, color code | [color.md](color.md) |
| Set type, sizes and line breaks | [typography.md](typography.md) |
| Write any public text | [voice.md](voice.md) |
| Use or draw a UI icon, set a shape beside text | [iconography.md](iconography.md) |
| Give a Project its Sign, set up its `brand/` folder | [project-brand.md](project-brand.md) |
| Write or restructure a README, or a repository's contributing and development docs | [readme.md](readme.md) |

Beyond this folder, the brand repository (`github.com/withvariablelab/brand`, the package `@variablelab/brand`) holds the tokens (`tokens/`), the Logo and the Class stamps (`assets/`), what a new Project copies (`templates/project/`: its README, its docs and its `brand/` folder) and the terms of use for the marks (`BRAND-USE.md`).
