# Variable Lab brand

Variable Lab is Variable Land's open source arm. This guideline holds its rules for anything public: sites, READMEs, package pages, images and icons. It states rules, never one Product's specifics: a Product's Sign lives in that Product's repository, and a site's page specs live in that site.

Terms in capitals are defined in [glossary.md](glossary.md).

Read the chapter the task touches:

| Task | Chapter |
| --- | --- |
| Any public work: the rules everything else follows | [principles.md](principles.md) |
| Place, size or link the Logo | [logo.md](logo.md) |
| Pick or check a color, color code | [color.md](color.md) |
| Set type, sizes and line breaks | [typography.md](typography.md) |
| Write any public text | [voice.md](voice.md) |
| Use or draw a UI icon, set a shape beside text | [iconography.md](iconography.md) |
| Give a Product its Sign, set up its `brand/` folder | [product-brand.md](product-brand.md) |

Beyond this folder, the brand repository (`github.com/withvariablelab/brand`, the package `@variablelab/brand`) holds the tokens (`tokens/`), the Logo and the Class stamps (`assets/`), the template for a Product's `brand/` folder (`templates/product/brand/`) and the terms of use for the marks (`BRAND-USE.md`).
