# Voice

Brief and declarative, in English. Say facts a reader can check in the code or the README. Every sentence ends with a period. No marketing, no exclamation marks, no emoji, no invented numbers, no clients or case studies.

## Names

- "Variable Land" and "Variable Lab": two words, always.
- A Product's name is lowercase kebab-case (`my-product`), in titles too.
- A Product's name is its title. Its executable and its package are metadata, shown beside the name, never instead of it.
- In Markdown, a scoped package name goes in backticks (`` `@scope/name` ``). Bare, GitHub links it as a mention of someone else's account.

## Saying what it is

- Name what a Product does or guarantees, in the words its code uses.
- Say what it leaves out when that is concrete and checkable: a file, a package, a behavior.
- Check every claim against the code before it ships, not only against the README.
