# Variable Lab brand

The language of Variable Lab's brand guideline: the house, its Products and their shapes. Sites that use the guideline keep their own glossary for their pages and content.

## The house and its marks

**Variable Land**:
The parent house. It builds software that is published, through Variable Lab, and software that isn't. Its name is the one set beside the Logo.
_Avoid_: VL

**Variable Lab**:
Variable Land's open source arm: its published Products and this guideline. It names the GitHub org and the guideline, never the text beside the Logo.
_Avoid_: Variable Labs, VL

**Logo**:
The hexagon with the V. In green it is Variable Lab's; in black, Variable Land's. No Product uses it.
_Avoid_: sign, wordmark, icon

**Signature**:
The Logo with "Variable Land" set in text beside it: how the house signs what it publishes.
_Avoid_: lockup, wordmark, house mark

## Products

**Product**:
Something Variable Lab publishes and owns. It is an App or a Library.
_Avoid_: project, tool, package, repo

**Class**:
Whether a Product is run or imported: App or Library.
_Avoid_: type, kind, category, badge

**App**:
A Product you run from a terminal.
_Avoid_: CLI, tool, binary

**Library**:
A Product you import from code.
_Avoid_: lib, SDK, module, package

## Shapes

**Sign**:
A Product's own shape: filled geometry in one ink. It belongs to the Product; this guideline says how a Sign is drawn, not which one a Product has.
_Avoid_: logo, icon, mark, glyph

**Class stamp**:
The shape of a Class. A Product carries it until it earns a Sign.
_Avoid_: badge, pill, tag, class icon
