# Principles

The rules every other chapter follows.

- **Variable Lab's own.** Variable Lab is Variable Land's open source arm, and this guideline is its own. Everything it publishes follows it: sites, READMEs, package pages, images.
- **Dark only.** Every Variable Lab surface uses the dark palette in [color.md](color.md).
- **One Signature.** Everything is signed with the Signature: the Logo with "Variable Land" set in text beside it ([logo.md](logo.md)). A Project adds its Sign and nothing else: no Signature, color, wordmark, letter, italic name or small-caps eyebrow of its own.
- **One version.** The Logo, each Class stamp and each Sign exist in one version. A shape is never redrawn alone.
- **Two Classes.** An App is run; a Library is imported. Every Project is exactly one.
- **Open source is the context.** It is what Variable Lab is, so it never appears as a badge or a selling point.
- **Flat.** No gradients, no shadows. Square corners on every box, block and panel. Borders and rules are 1px in `rule`.
- **Facts.** English, checkable, without clients, case studies or invented numbers ([voice.md](voice.md)).
