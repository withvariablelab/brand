# Logo

The hexagon with the V. In green (`logo`, `#36d399`) it is Variable Lab's, and it is the only version this guideline covers. In black it is Variable Land's and falls outside these rules.

File: `assets/logo.svg` in the brand repository, `viewBox 0 0 402.02 468.12`.

## Use

- Green, on `ground`, at its own proportions: scale it, never stretch it.
- The Signature is the Logo with "Variable Land" beside it, the Logo on the left, the name in IBM Plex Sans 500 in `ink`. The name is set as text each time; there is no wordmark file.
- Smallest size: 16px wide (16×18).

## Avoid

- Another color, an outline, or a background other than `ground`.
- "Variable Lab" beside it: the name beside the Logo is Variable Land.
- A Project using it as its own mark, or the Logo locked up with a Sign. A Project's page or docs still carry the Signature, set apart from the Sign.
- A drawn wordmark or any other variant.

## Linking it

From outside the brand repository, link a pinned version so it never changes under a page: `https://cdn.jsdelivr.net/npm/@variablelab/brand@<version>/assets/logo.svg`. jsDelivr caches a pinned version for good and a range for days.
